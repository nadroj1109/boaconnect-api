3. Backend integration tools and libraries

Tool or technology	How it is used
Laravel 12			
- Main backend framework for BOAConnect's blockchain integration, proof preparation, anchor records, and verification logic.

web3p/ethereum-tx	
- Signs EIP-1559 transactions locally using the configured private key. The EIP1559Transaction class is used for type-2 transaction signing.

web3p/ethereum-util	
- Provides Ethereum Keccak-256 hashing used to calculate the locally signed transaction's hash.
Laravel HTTP client	Sends JSON-RPC requests to read the chain, retrieve proofs and receipts, estimate gas, obtain fee parameters, and—once submission is enabled and invoked—broadcast signed transactions.

Ethereum JSON-RPC API	
- Protocol used by Laravel to communicate with the local Hardhat node and Sepolia RPC endpoint.
EIP-1559 transaction format	Defines the signed transaction fields, including chain ID, nonce, gas limit, priority fee, maximum fee, destination, and calldata.

ABI encoding	
- Encodes calls to anchorProof(bytes32,bytes32,uint8) and decodes contract responses.

Cryptographic operations
The integration uses two distinct kinds of hashing:
- SHA-256 is used in the BOAConnect proof-identifier construction for anchors.
- Ethereum Keccak-256 is used for Ethereum-compatible transaction hashing and the contract's proof/event conventions.


Development Tools and Technologies

The blockchain component of BOAConnect was developed using Solidity for smart-contract programming and Hardhat for the Ethereum development environment. The BOAConnect Proof Registry smart contract was deployed to the Ethereum Sepolia test network, with Alchemy providing the JSON-RPC endpoint for blockchain communication. Etherscan was used to inspect the deployed contract and its deployment transaction.

The blockchain integration was implemented in Laravel 12 using PHP. The web3p/ethereum-tx library supports local signing of EIP-1559 transactions, while web3p/ethereum-util provides Ethereum-compatible Keccak-256 hashing. Laravel's HTTP client communicates with the blockchain through the Ethereum JSON-RPC API, while Eloquent ORM and MariaDB manage the application's source records and blockchain anchor metadata.
