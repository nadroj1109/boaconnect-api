For Windows:

Option 1: Allow scripts for your current Windows user (Recommended)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Option 2: Temporary workaround (Current PowerShell session only)
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

Active venv
py -3.14 -m venv .venv

.venv\Scripts\Activate.ps1
.venv\Scripts\activate

python -m pip install --upgrade pip

pip install -r requirements.txt

Option 3: Don't activate the environment
You can directly execute Python and pip using their full paths:
.venv\Scripts\python.exe --version
.venv\Scripts\python.exe -m pip install -r requirements.txt
